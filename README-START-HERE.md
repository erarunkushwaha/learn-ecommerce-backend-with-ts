# Start Here: Cursor Backend Interview Lab

**The documentation is a plan, not generated backend code.**

1. Open this folder as a project in Cursor (rename it to `ecommerce-backend` if desired).
2. Make sure the files `AGENTS.md` and `docs/*.md` are present.
3. Start a **fresh Agent chat** and paste `prompts/01-FIRST-TASK.md` (copy the prompt text, not necessarily the heading).
4. Cursor implements F01 and updates `docs/PROGRESS.md`; review changed files and test results. Make a Git commit.
5. For the next task, use a **new Agent chat** and paste `prompts/02-NEXT-TASK.md`.
6. To study the generated implementation, use Ask mode with `prompts/03-EXPLAIN-CODE.md`.
7. Repeat one task at a time. The roadmap keeps long-term scope; progress keeps the current handoff; checklist tracks interview learning.

## Files
- `AGENTS.md`: always-on instructions
- `docs/PROJECT.md`: complete project scope
- `docs/ARCHITECTURE.md`: architecture guidelines
- `docs/DATABASE.md`: proposed DB schema and advanced SQL coverage
- `docs/ROADMAP.md`: fine-grained task list
- `docs/PROGRESS.md`: next task/verified outcomes/blockers
- `docs/DECISIONS.md`: architectural decision records
- `docs/INTERVIEW-CHECKLIST.md`: coverage checklist

## Important
- *Do not ask Cursor to complete all roadmap items in one prompt.*
- Each task should end with verification and a concise file-based handoff, not an enormous chat history.
- Cursor may need local Node/MySQL/Docker tools installed to run specific verification steps. Record unavailable dependencies honestly.
